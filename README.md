# Ridiculous at First Glance, Real by the Second

Entry for the make.fun competition
`u-po-pu-ridiculous-at-first-glance-real-by-the-second-9a97d12a`.

`main.py` (Python 3.13 standard library only, no network) writes one
sentence of at most 200 characters to `/output/entry.txt`, pitching a
bizarre startup idea that sounds ridiculous at first glance but makes
sense as a real business: selling naming rights to potholes, sponsored
by the local businesses outside whose doors the holes sit.

## How to run

```sh
python3 main.py
cat /output/entry.txt
```
